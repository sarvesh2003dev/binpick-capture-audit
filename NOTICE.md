# Third-party data and attribution

The DIMO comparison image and reported measurements are derived from the
Dataset of Industrial Metal Objects (DIMO) by Peter De Roovere, Steven Moonen,
Nick Michiels and Francis Wyffels.

DIMO is licensed under Creative Commons Attribution 4.0 International (CC BY
4.0). The public repository does not redistribute the original RGB/depth
captures or CAD archive. It contains a derived visualization and numeric
summaries. The visualization adds crops, CAD outlines, recoloring and labels.

- Dataset project: https://pderoovere.github.io/dimo/
- License statement: https://pderoovere.github.io/dimo/usage/
- License text: https://creativecommons.org/licenses/by/4.0/
- Paper: https://arxiv.org/abs/2208.04052

The Isaac Sim foundation under `experimental/isaac/` is provided as source
code only. No Isaac Sim frames are included; GPU execution is unverified.
